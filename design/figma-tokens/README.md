# משתני Figma - מיטב מתגייסים

הקבצים כאן נוצרו מהערכים שבקוד (`src/app/themes.ts`,
`src/styles/themes.css`, `src/app/components/primitives.tsx`) ומיועדים
לייבוא ל-Figma דרך פלאגין שתומך ב-W3C Design Tokens
(Variables Import / Tokens Studio).

## מבנה האוספים

**שם התיקייה = שם האוסף ב-Figma, שם הקובץ = שם ה-mode.** זהו המבנה
שהייצוא מ-Figma מייצר, ולכן זה גם המבנה לייבוא חזרה:

```
figma-tokens/
├── Value.tokens.json      ← אוסף המשתנים הקבועים (mode יחיד)
└── Theme/                 ← אוסף הערכות
    ├── בהיר.tokens.json
    ├── כהה.tokens.json
    ├── סגול.tokens.json
    ├── טורקיז.tokens.json
    ├── שקיעה.tokens.json
    ├── ורוד.tokens.json
    └── צבעוני.tokens.json
```

שבעת קובצי הערכות מכילים **בדיוק את אותם שמות משתנים** (101 בכל
קובץ) - זה תנאי לכך שהם ייטענו כ-modes של אותו אוסף. אין לערבב את
`Value.tokens.json` לתוך `Theme/`: סט המשתנים שלו שונה, וזה מפיל את
הייבוא.

## מה יש ב-Primitives

- `radius` - 8 / 10 / 16 / pill, ובנוסף הרדיוסים של הערכה הצבעונית (14 / 20).
- `type` - סולם הטיפוגרפיה של **הדסקטופ** (10→52).
- `type-mobile` - אותו סולם אחרי ההקטנה האוטומטית מתחת ל-768px.
- `line-height`, `font-weight`.
- `space` - סולם 4-40 + ריפוד כרטיס וריפודי עמוד לפי רזולוציה.
- `size` - אייקונים, עיגולי אייקון, גובה כפתור/צ'יפ/שדה, נקודות.
- `layout` - רוחב תוכן, נקודות שבירה, רוחבי חלונות, גבהי רשימות,
  מידות הקרוסלה, גובה שטח הפרסום.
- `elevation` / `opacity` / `duration` / `z-index`.

## מה יש בכל Theme

- `brand` - הצבע וגווני השקיפות שלו (6% / 8% / 10% / 12% / 18%).
- `accent-2` - הצבע המשני (הנקודה שבסוף כותרת).
- `background` - רקע העמוד ושני צבעי הכתמים.
- `nav-gradient/stop-1..4` - ארבע העצירות של סרגל הניווט.
- `surface` - כרטיס, משטח משני, זכוכית, צ'יפ, כהות הרקע של חלון.
- `ink` - טקסט ראשי/משני/עמום וקווי הפרדה.
- `semantic` - הצלחה / אזהרה / שגיאה / מועדף + רקעיהם.
- `elevation` - צבעי הצללים.
- `header/bar` - נייבי `#122736`, זהה בכל הערכות.
- `accent/<עמוד>` - הגוון של כל עמוד: `default`, `hover`, `accent-2`,
  `page-bg`, `surface` וגרדיאנט ניווט משלו.

> בערכה **צבעוני** לכל עמוד גוון אחר (פרופיל סגול, זימונים כתום,
> משימות טורקיז, לומדות ירוק, פניות ורוד, הודעות כחול, הגדרות סגול).
> בכל שאר הערכות `accent/<עמוד>` שווה לצבעי הערכה - בדיוק כמו
> `accentFor()` בקוד. כך אפשר לעצן מסך אחד ולהחליף גם ערכה וגם עמוד.

## עדכון

הקבצים נוצרים מסקריפט; כשמשנים צבע או טוקן בקוד יש לייצר אותם מחדש
ולייבא ל-Figma, כדי ששני הצדדים לא ייפרדו.

## מה עדיין לא כאן

- **צללים כאובייקט אחד** - Figma לא תומך במשתנה מסוג shadow; יש כאן
  את צבע הצל ואת המספרים (`elevation`), וההרכבה נעשית בסגנון אפקט.
- **גרדיאנטים** - שמורים כארבע עצירות צבע ולא כמשתנה גרדיאנט.
- **ערכת "אפליקציה"** (כרטיסים בנייבי על עמוד בהיר) מושבתת כרגע בקוד
  ולכן לא ייוצאה. אם היא חוזרת - `surface/card` שלה `#122736`
  ו-`surface/muted` `#1C3346`.
